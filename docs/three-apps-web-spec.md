# 八字、紫微、星座：完整免費網頁版

日期：2026-10-23。狀態：三款完整移植、依序上線的規模與 15 項工作單均已核准；實作中。

## 問題描述 / Problem Statement

Michael 希望把已寫好的命理 App 免費公開於個人網站，讓訪客能實際使用，也讓搜尋引擎與 AI 有可引用、可爬取的公開內容。易見已公開，剩餘三款仍只有 App 介紹。

不能把舊原型、未核准規則或設計展示當成完整產品，也不能只公開介紹頁便宣稱移植完成。三款各自需要可用的出生輸入、原有排盤與解讀、既有課程及瀏覽器資料管理。

## 解決方案 / Solution

- 在既有 GitHub Pages 根站依序提供 `/bazi-web/`、`/ziwei-web/`、`/astrology-web/`。
- 每款延續易見已核准的美術館式網站體驗：暖紙、墨色、克制金棕、大標、清楚的展廳動線與有教學用途的圖解；保留三種領域各自的辨識方式。
- 免費、免登入、手機與電腦可用。公開作者名稱只用 Michael。既有會員課與已實作的進階解讀在網頁版全部開放。
- 繁體中文採台灣常見口吻；主要入口附易懂短英文。原 App 已有的完整英文教材與解讀保留並對應相同穩定 ID。
- 可公開的課程與知識頁輸出完整 HTML；個人計算結果只在瀏覽器中顯示，不建立含生日的公開網址。
- 每款功能與驗證完成後，依既有上線授權發布，加入 App 作品站與個人網站首頁。無需逐票再次詢問例行執行與發布。

## 用戶故事 / User Stories

1. 訪客從個人網站選擇八字、紫微或星座，可以免費輸入出生資料並取得真正計算出的盤。
2. 初學者可以先讀完整既有課程，不必先填出生資料；示範盤清楚標示，不冒充個人結果。
3. 不知道出生時間的訪客可以看可靠的部分結果，並清楚知道哪些欄位無法確定。
4. 訪客能閱讀原 App 已有的命盤解說、今日／未來內容與比較功能，看到所用規則或資料限制。
5. 訪客可以在目前瀏覽器保存、切換、刪除自己的資料，保留筆記與閱讀進度，並知道資料不會跨裝置同步。
6. 搜尋引擎與 AI 可以找到每款工具、課程、來源與使用說明，而個人出生資料不會出現在索引內容。

### 計算與解讀

- 八字與紫微已存在 JavaScript 引擎。優先沿用已鎖定的 `lunar-javascript 1.7.7`／`iztro 2.6.1` 與原程式，保留授權與版本；不得默默升版。
- 不能把八字引擎順帶產生的紫微資料當成正式紫微 App 的完整實作；需以紫微自己的輸入、盤面、解讀與驗證為準。
- 八字保留四柱、五行、十神、缺出生時間處理、命盤解說、已有的每日與七日功能。原 App 已有的合盤與進階頁面納入功能對照後一併移植。
- 紫微保留十二宮、命身宮、星曜與四化、原有解讀與運限、已實作的合盤。邏輯需能對照原 App 的資料結果，不能用網站原型的通用文案替代。
- 星座保留十星、回歸黃道、ASC／MC、五大相位、Placidus 宮位與明示 Whole Sign fallback、部分盤、每日／七日行運與已有合盤。使用與原 App 相同的星曆版本和容許度；任何替換實作必須先通過數值與語義對照。
- 出生地歷史民用時間、時區、夏令時間、日期支援範圍、閏月、23 時跨日等，按各原 App 的合約處理。未知出生時間不自行帶入中午或零點作確定盤。
- 沿用有來源且已核准的解讀；未核准、未驗證或缺授權部分保留原本阻擋狀態。不額外生成批量新教材、不捏造分數、不增加即時 AI 預測。

### 課程與個人資料

- 移植全部現有教材、來源、例子、圖解說明、已存在的練習與答案。八字 20 堂、星座 36 堂；紫微數量以來源快照中的正式課程清單驗收。
- 原生程式繪製的課程圖解轉成可讀的網頁圖解，提供文字替代；不把截圖當可互動課程。
- 來源本身缺少或未完成的課程區塊列入差異清單，不靠補寫新內容掩蓋。
- 命盤、人物比較、筆記、閱讀進度及已存在的複習狀態按穩定 ID 保存在本機。不同 App 使用獨立儲存命名空間。
- 提供明確的刪除確認、儲存失敗提示及資料恢復行為；不宣稱跨裝置同步或永久備份。
- 不把出生資料、筆記或比較對象資料放入網址、分析事件、公開日誌、搜尋資料、社群預覽或生成的靜態頁。

### 發布與搜尋

- 舊 `/bazi/`、`/ziwei/`、`/astrology/` App 介紹繼續存在並連向免費工具；不覆蓋其他獨立 GitHub Pages 專案。
- 每款完整課程、FAQ、來源說明、canonical、描述、結構化資料及 sitemap 一起上線；個人資料頁不索引。
- 更新根站作品入口、`llms.txt` 與個人網站首頁。個人網站若落後遠端或有未追蹤資料，從最新遠端建立乾淨工作區，只發布本次入口變更。
- 發布後以正式 HTTPS 網址驗證新內容、照片／程式資源、課程與主要操作。預覽連結使用可用網址，不把會清理的暫存檔交付為正式入口。
- 可改善搜尋與 AI 理解條件，不保證排名、收錄日期或特定 AI 推薦。

## 測試決策 / Testing Decisions

- 先凍結原生／JavaScript 引擎的合成測例，再對照網頁輸出。每款須覆蓋支援範圍內的一般案例及邊界案例，不只自我比對新網頁程式。
- 八字：四柱、時間已知／未知、干支跨日、節氣月界、閏月／農曆輸入、歷史時區與原有解讀觸發結果。
- 紫微：各出生時辰、農曆月份與閏月、十二宮與命身宮、主輔星／四化、運限、缺時間阻擋與原有合盤結果。
- 星座：星體黃經與逆行、相位命中與容許度、ASC／MC、十二宮、極緯 fallback、歷史 DST、未知時間的不確定性、行運與合盤。容差與判斷需來自原測試或明示推導，不能自行放寬到剛好通過。
- 課程：數量、穩定 ID、繁英內容、來源、練習與答案對照來源；確認無付費牆、可在無個人盤狀態學習。
- 瀏覽器：建立／切換／重載／刪除命盤、筆記保存、無痕與停用儲存、錯誤恢復、結果不洩漏到網址。
- 介面：手機與桌面、鍵盤、標籤、焦點、圖解文字替代、減少動態模式、無橫向溢出。
- 每票只跑相關檢查；每款公開前跑該款完整網頁驗收與易見／共用導覽回歸。若未改原生程式，不啟動 iOS UI 測試或模擬器。
