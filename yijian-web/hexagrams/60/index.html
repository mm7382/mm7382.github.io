節卦

節度要設在撐得久的位置，太鬆會溢出，太緊會折斷

卦辭與白話

節：亨。苦節不可貞。

彖傳：「節，亨，剛柔分，而剛得中。苦節不可貞，其道窮也。說以行險，當位以節，中正以通。天地節而四時成，節以制度，不傷財，不害民。」象傳：「澤上有水，節；君子以制數度，議德行。」彖傳說節之所以亨通，在於剛柔各得其分而剛爻居中；至於過苦的節制之所以不可固守，是因為那條路已經走到盡頭。以和悅之心走過險境，居於當位而行節制，中正因此通達。天地有節度才成就四時，以制度行節制，便不損傷財貨、不危害人民。象傳取澤上有水、澤有容量限度之象，君子由此制定度量標準、評議德行。（《周易·彖象傳》，公有領域）

兌下坎上，澤上有水，是節制的卦。節的本義是竹節：一段一段，有明確的界線。澤能容水但有容量，超過就溢出，所以需要節度。卦辭說節制能通達，但緊接著提醒「苦節不可貞」——把自己逼到痛苦的節制，不能長久固守。六爻從初九知道路不通而不出戶庭、九二該出門卻不出而凶，經六三不知節制只能嗟嘆、六四安於節制而亨，到九五以甘美的節制得吉，最後上六苦節貞凶但悔恨消失。整體提醒：節度要設在能長期維持的位置，太鬆會溢，太緊會斷。

卦辭先說「亨」，隨即以「苦節不可貞」加上限制條件，正反同時出現。爻辭亦兩端並陳：六四「安節，亨」、九五「甘節，吉；往有尚」明確有利，初九「不出戶庭，无咎」、六三「无咎」屬無過失；但九二「不出門庭，凶」象傳稱「失時極也」，上六「苦節，貞凶」象傳稱「其道窮也」，兩爻直接繫凶。吉凶完全取決於節度拿捏得是否恰當——同樣是不出門，初九得无咎而九二得凶，差別只在時機，故評為中性。此評級是本 App 對文本的詮釋，不是結果保證。

宜做：設定能長久遵守的界線，讓資源與時間有節度。避免：規定過鬆造成失控，或限制過嚴使人無法持續。

從結構讀懂這一卦

上坎下兌：澤在下、水在上，有邊界才裝得住。

  • 指出節的上卦與下卦各是什麼。
  • 說出為什麼限制在這裡是正面的。
  • 說出把上下卦交換之後，節會變成困。

節的下卦是兌：初爻與第二爻實線、第三爻斷線。上卦是坎：第四爻斷線、第五爻實線、第六爻斷線。整卦第一、第二、第五爻是實線。

兌是澤，澤之所以是澤，是因為有岸。水再多，沒有邊界就不叫澤。這一卦談的是節制：限制不是減少，是讓東西留得住。節的難處在量——太鬆裝不住，太緊也裝不住，所以傳統在這一卦特別強調「甘節」而不是硬節。

教學示例，不是結果預測：一個團隊規定每次最多三個進行中的工作，不是為了少做，是為了做得完。節描述的是這種結構。

六爻原文與反思

初九：不出戶庭，无咎。

象傳：「不出戶庭，知通塞也。」不走出自家門戶之內的庭院而沒有過失，象傳指出關鍵在於他明白眼下是通還是塞。戶庭，指室門之內的庭，比門庭更近、更內。（《周易·象傳》，公有領域）

連自家門內的庭院都不出去，卻沒有過失。因為他清楚知道現在是走得通還是走不通的時候。

時機不對時按兵不動，不是懶散而是判斷。關鍵是你要說得出來自己在等什麼，而不是單純不敢動。

你現在的按兵不動，是判斷還是逃避？

九二：不出門庭，凶。

象傳：「不出門庭，失時極也。」不走出大門之外的庭院，結果是凶；象傳說原因在於錯失時機已到極點。與初九同樣是不出，差別在於此時門已可出而不出。（《周易·象傳》，公有領域）

同樣是不出門，這一次卻是凶。因為門已經可以走出去了還不走，時機就這樣被錯到底。

過度謹慎會從保護變成損失。當你發現身邊條件都齊了卻還在找理由拖，那不是穩重，是錯過。

有沒有一個機會，條件都到了而你還在等？

六三：不節若，則嗟若，无咎。

象傳：「不節之嗟，又誰咎也。」不知節制便只能嗟嘆；象傳反問「又能怪誰呢」，說明爻辭所謂无咎，是指此事無從歸咎他人，責任在己。（《周易·象傳》，公有領域）

不肯節制，接著就只剩嗟嘆。爻辭說无咎，象傳解釋得很直白：這件事怪不了別人。

熬夜、超支、話說太滿之後的後悔，通常都不是別人造成的。承認這點不好受，但這是唯一能改的起點。

最近讓你後悔的那件事，有幾分是自己放縱的結果？

六四：安節，亨。

象傳：「安節之亨，承上道也。」安然處於節制之中而亨通，象傳指出其所以如此，是因為順承在上者所立的正道，節度不是自己硬撐出來的。（《周易·象傳》，公有領域）

安安穩穩地待在節制之中，所以亨通。象傳說原因是他順著上面既定的正道走，不必自己咬牙硬撐。

好的節制應該讓人覺得安穩，而不是每天在跟自己打仗。如果一個規矩你需要天天抗拒才能遵守，多半是訂得不合身。

你替自己訂的規矩，是讓你安心還是讓你疲倦？

九五：甘節，吉；往有尚。

象傳：「甘節之吉，居位中也。」甘美的節制得吉，前往還會受到嘉尚；象傳指出其吉來自九五居於中位——節度得中，所以不苦反甘。（《周易·象傳》，公有領域）

節制得恰到好處，甚至讓人覺得甘美，所以吉；再往前走還會受到推崇。關鍵就在一個「中」字。

最好的自律是你自己也喜歡的那種：吃得剛好、花得剛好、忙得剛好。做到這個程度，別人自然會學你。

有沒有哪個好習慣，你做起來其實是享受的？

上六：苦節，貞凶，悔亡。

象傳：「苦節貞凶，其道窮也。」把節制推到痛苦的程度，固守下去是凶，象傳指出那是因為這條路已經走到窮盡；然而爻辭又說「悔亡」，表示在極端處境中甘受其苦，尚可無所悔恨。（《周易·象傳》，公有領域）

節制到痛苦的地步，一直守著就是凶，因為這條路已經走不下去了。不過爻辭還說悔恨會消失——苦得心甘情願，至少不留遺憾。

把自己逼到極限的節省或自律，撐不了太久。若這是你當下非走不可的路，至少替它設一個結束的時間點。

你正在硬撐的那件事，打算撐到什麼時候為止？

為什麼說節的限制是正面的？

有邊界才裝得住（正確）：對。兌是澤，澤靠岸才成立。

因為限制就是減少：卦講的是留得住，不是減少。

因為越緊越好：太緊也裝不住，量才是難處。

節的上卦是哪一個三爻卦？

坎（上下斷、中間實）（正確）：對。第四爻斷、第五爻實、第六爻斷。

兌（下兩實、上一斷）：兌在節裡是下卦。

巽（下一斷、上兩實）：節的第六爻是斷線。

節的難處在哪裡？

在量：太鬆或太緊都裝不住（正確）：對。所以傳統強調能維持得下去的節制。

在完全沒有限制：那正是卦要處理的對象。

在水太多：水多不是問題，沒有岸才是。
